ShowUp widget demo

Any event page can embed a ShowUp event with one tag: <script src="/widget/widget.js" data-event="EVENT.testnet"></script>. Event data comes from live testnet RPC view calls. The quote is a live 1Click dry quote. Add ?relayer=http://localhost:3030 (with pnpm relayer running) to cancel gaslessly, or ?event=<account> to show another event.
